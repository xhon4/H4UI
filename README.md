# H4UI

## Instalar

```
git clone https://github.com/xhon4/H4UI.git
cd H4UI
./install.sh
```

Eso es todo — `install.sh` instala los paquetes, las fuentes, copia todo a su lugar y activa
el tema de login. Al terminar, la carpeta clonada se puede borrar tranquilo: nada en tu sistema
depende de que siga ahí (`h4ui cheatsheet` funciona igual; solo `h4ui update`
necesita el repo original, para poder hacer `git pull`).

Detalles del instalador (qué hace cada fase, requisitos) → [`INSTALL.md`](INSTALL.md).
Cómo se diseñó todo esto y por qué → [`DEVELOPMENT.md`](DEVELOPMENT.md).

## Empezá acá (si es tu primera vez en Linux)

- **Abrir cosas:** `Super + Return` = terminal · `Super + A` = buscador de apps · `Super + E` = explorador de archivos.
- **¿Te perdiste con los atajos?** Apretá `Super + /` en cualquier momento — se abre una ayuda en pantalla con todo.
- **Wifi:** hay un ícono de red en la barra de arriba a la derecha, click y elegís tu red — no hace falta terminal.
- **¿Más ayuda?** Pedile una mano a quien te instaló esto. Vas a aprender rápido, tranqui.
